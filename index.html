UI Elements Reference

Twenty zero-dependency HTML files plus a motion library and one reusable component package. Each file is self-contained: open it, switch light and dark, copy what you need. Built for operations consoles and modern SaaS products that should not look generated. Start with file 18 if you are deciding a look, file 11 if you are building a screen, files 08–10 if you are picking a theme.

Conventions. Every file defines the same token set under [data-t="dark"] and [data-t="light"] and every component reads only from tokens, so a theme block from files 08–10 pasted over the dark block re-skins any file. Page chrome is always dark; demo panes switch. Files are numbered contiguously; the two motion files are unnumbered on purpose.
