03 — Print stylesheet

The six rules that do the work

Most print output is broken by four omissions: interactive chrome left in, dark backgrounds carried over, no break control, and table headers appearing only once. This block fixes all four.

Light
/* Ship this alongside your app stylesheet */ @media print { /* 1. Remove all interactive chrome */ nav, aside, .toolbar, .fab, button, .no-print { display: none !important; } /* 2. Force economical colour */ * { background: #fff !important; color: #000 !important; box-shadow: none !important; } /* 3. Control page breaks */ h1, h2, h3 { break-after: avoid; } table, figure, .card { break-inside: avoid; } .page-break { break-before: page; } /* 4. Repeat table headers on every page */ thead { display: table-header-group; } tfoot { display: table-footer-group; } /* 5. Expose link targets */ a[href^="http"]::after { content: " (" attr(href) ")"; font-size: 9pt; } /* 6. Page setup */ @page { margin: 18mm 15mm; size: A4 portrait; } }

04 — Checklist

What to verify before shipping export

Test by actually printing to PDF and scrolling every page. Print bugs are invisible in the browser and obvious the moment someone brings a stack of paper to a meeting.

Light
Pre-export checklist
✓ Headers repeat per page. thead { display: table-header-group } — without it, page four is an unlabelled grid of numbers.
✓ Charts survive greyscale. Hatching and fill density instead of hue. Test by printing in black and white, not by looking at the colour preview.
✓ Generation timestamp and page numbers. A printed report with no date is worthless three weeks later.
✓ Link URLs exposed. A hyperlink on paper is dead unless the href is printed.
× Dark theme carried into print. A dark background wastes an entire toner cartridge and most printers render it as muddy grey.
× Screenshots of tables. Rasterised data cannot be searched, copied or reflowed. Render real markup.
× Interactive elements left in. Buttons, filters and empty search boxes printed on paper look like a bug.

Porting notes. Build the print stylesheet at the same time as the screen one, not as a retrofit — retrofitting means hunting every box-shadow and dark background across the whole app. Verify with an actual export to PDF rather than the browser print preview, which lies about page breaks. If executives receive the output by email, assume it will be printed and forwarded, so the header must carry the date range, the generation timestamp and a confidentiality marking.
