Gemini-Style Mobile Assistant

A phone-frame reconstruction of the Gemini iOS app's "Neural Expressive" / "Liquid Glass" redesign (rolled out iOS-first around May 2026): a translucent pill composer, a pulsing four-colour gradient wash across the top of the screen while thinking instead of an inline spinner, reasoning tucked into a bottom sheet rather than shown inline, and sources as a tappable chip that opens a sheet. Same conceptual data — a question, reasoning, grounding/search steps, an answer, sources, follow-ups — presented in a completely different visual language from files 07/20.

⚠ Reduce Motion is on in your OS. The pulsing wash and other animations are being suppressed.
This file intentionally breaks the restraint rules elsewhere in this set — multi-hue gradient, glow, motion at rest. That's deliberate: the goal here is accurately reproducing one specific, named product's identity, not a generic default. Built from public write-ups of the redesign (no App Store screenshots were available to verify pixel-for-pixel) — treat colours and exact spacing as a close approximation and check against your own installed app before shipping anything derived from it.

Mapping notes. Gemini has no ops-console-style bordered tool-call row — a search/grounding step is a single line of dim text with a small pulsing dot, replaced once the answer starts streaming. There is no assistant message bubble; the response is plain text starting at the left margin, marked only by the small spark. Reasoning is hidden by default behind a "Show thinking" chip that opens a sheet, not an inline collapsible. The composer's right-hand icon swaps between mic and send based on whether the field has text — try typing. The pulsing wash is the one loud element in the whole screen; everything else stays quiet specifically so that wash reads as meaningful.
