01 — Split panes

Draggable horizontal and vertical dividers

Store the ratio as a percentage rather than pixels so it survives a window resize, and give both panes a min-width so a fast drag cannot collapse one to zero. The cursor changes on the handle itself, not on hover of the whole edge.

02 — Multi-pane & sticky

Three-pane collapse and sticky headers

The nav/list/detail layout drops its detail pane first and collapses nav to icons second — never reverse that order, since the detail is reachable by other means and the nav is not. Sticky headers need a background; transparent ones let content scroll through them.

03 — Scroll-spy & masonry

Position-aware navigation

The TOC highlights based on which section header is nearest the top of the scroll container, not on click. Masonry via CSS columns costs nothing but reads top-to-bottom per column — wrong if reading order matters, fine for a dashboard of independent tiles.

05 — Progressive loading

Infinite scroll sentinel

The sentinel sits below the list and triggers a fetch when it approaches the viewport. Always pair infinite scroll with a visible count and a way to jump — users need to know how much is left, and deep-linking to item 400 is impossible otherwise.

06 — Board

Kanban with native drag and drop, WIP limits and collapsible columns

Columns are a horizontally scrolling flex row; cards move with the HTML5 drag API and a two-pixel placeholder line shows where the drop will land. The In-progress column carries a WIP limit of three: drag a fourth card in and the count, the limit and a warning all turn red. Column headers click to collapse into a vertical label.

Porting notes. Split-pane ratios belong in percentages, not pixels, or every window resize breaks the layout. Persist them to storage per user — people rebalance panes once and expect it to stick. For responsive tables, decide early whether a column is essential or supplementary; the phone card view should show only the essentials, not every column stacked, which is just a slower version of horizontal scroll.
