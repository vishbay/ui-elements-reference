Assistant Panel

The reusable core: a data schema, a vanilla-JS renderer and a Vue wrapper that calls the same renderer, all in assistant-panel/. This page loads them exactly the way a real project would — as ES modules — and drives them with mock data (demo.js) that documents the block shapes a real backend needs to produce.

Opened via file:// — ES module imports are blocked by the browser here. Serve this folder instead, e.g. python3 -m http.server in the repo root, then open http://localhost:8000/ui-ref-20-assistant-panel.html. GitHub Pages and any real project's dev server already serve over http(s), so this only affects opening the file directly by double-clicking it.
What's reusable. schema.js, panel.css and renderer.js are the package — copy the assistant-panel/ folder into any project unchanged. demo.js is not part of it; it exists only to prove the renderer works and to show the exact block shapes (see it running above: thinking, staggered tool calls, a failed tool with retry, streamed text with citations, suggested follow-ups). For Vue, use assistant-panel/vue/AssistantPanel.vue instead of calling renderer.js directly — it wraps the identical controller, so the interactions and animations are the same file in both stacks. Full wiring guide: assistant-panel/README.md.
