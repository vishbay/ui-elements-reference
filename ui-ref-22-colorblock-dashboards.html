UI Reference 22 · Colorblock Dashboards

Colorblock Dashboards & Onboarding

Reconstruction of a distinct, deliberately loud visual language — saturated pastel hero cards, huge rounded numerals, hatched bar charts and pill navigation — pulled from five reference screenshots of two real products (a support-AI analytics app and a delivery ops console) plus a standalone onboarding checklist card.

This file is intentionally off-system. It does not use the house --accent/obsidian token set from files 01–19 — four simultaneous hues, solid-fill bar charts, its own light/dark toggle per demo rather than the shared [data-t] convention. It exists because the source screenshots are a coherent, well-executed alternative to the restrained azure system: reach for it when a brief explicitly wants a warmer, more playful analytics or consumer-ops look, not as a default. Dark mode below is an original extension — the source products were only ever photographed in light mode, so the jewel-tone hero cards and inverted pill/circle chips are this file's own design decision, not a screenshot match. The hatch-fill bar (.cb-bar), sub-panel stat chip (.cb-sub) and pill nav (.rz-tab) are the reusable pieces; copy the .cb block wholesale if you adopt the look.
