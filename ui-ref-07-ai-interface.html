01 — Conversation

Thinking, tool calls, citations, actions, follow-ups

The full anatomy of an assistant turn. Tool calls appear as they run and settle into a completed state rather than vanishing — that visible trace is what makes an agentic answer trustworthy in an ops context. Hover a response to reveal its actions.

02 — Streaming & code

Token-by-token rendering and copyable blocks

Streaming needs a caret and needs to scroll as it grows, or long answers feel stuck. Markdown should render progressively rather than as plain text that reformats at the end — the reformat flash is what makes streaming look broken.

Porting notes. Render markdown progressively during streaming, not once at the end — parsing the partial buffer each tick costs little and avoids the reformat flash that makes streaming look broken. Keep tool-call rows in the transcript after they finish; collapsing them to nothing removes the audit trail that makes an agentic answer defensible. Citations should link to the underlying query or record, not just name a source.
